# Palco — Plataforma de Gestão de Eventos com Inscrições

**Integrantes:** _(Marcos Gabriel Rocha Galvão,Iago Vinicius Bandeira dos Santos, João Pedro Gonçalves De Lima, Iasmim Sales Rodrigues, Miguel Victor victor de Oliveira Santos)_

## Descrição da solução
Aplicação web (HTML, CSS e JavaScript puros, sem back-end) para organizar eventos, controlar vagas e gerenciar inscrições de participantes. Os dados ficam no `localStorage` do navegador.

## Principais funcionalidades
- Cadastro, edição e exclusão de eventos (com validação)
- Busca por nome/local e filtro por situação (disponível, lotado, encerrado)
- Cálculo automático de inscritos, vagas e % de ocupação
- Inscrição de participantes (bloqueia evento lotado, encerrado ou e-mail repetido)
- Lista de inscritos por evento, com busca e cancelamento de inscrição
- Mensagens de sucesso e erro; persistência após recarregar a página

## Como executar
Abra o `index.html` em qualquer navegador moderno. Não precisa de instalação nem servidor.
